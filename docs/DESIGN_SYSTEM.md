# Design System do APEX

Este documento registra a direção visual futura do APEX.

O design system ainda não está implementado por completo.

## Princípios visuais

- Interface limpa e focada no estudo.
- Hierarquia visual clara.
- Baixa distração durante sessões.
- Controles contextuais, exibidos quando necessários.

## Prioridade atual

A evolução pedagógica e a funcionalidade de estudo vêm antes da identidade visual definitiva.

## Interação

Os controles de estudo devem ser contextuais e aparecer conforme a necessidade, evitando excesso de elementos permanentes na tela.

## Direção futura

A identidade visual definitiva será consolidada depois que o fluxo pedagógico e as funcionalidades principais de estudo estiverem estáveis.
